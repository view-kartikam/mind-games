# Mind Games

A small browser-based cognitive game hub built with HTML, CSS, and JavaScript.

## Project structure

- `index.html` – main page and game layout
- `assets/css/styles.css` – all styling for the site
- `assets/js/app.js` – game logic and interactions
- `assets/audio/` – sound files for the game

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local server:

```bash
cd "c:\Users\karti\Documents\GitHub\mind games"
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

Place your sound files in `assets/audio/` using the names referenced in the app:

- `keyboard.mp3`
- `lose.mp3`
- `win.mp3`
- `start.mp3`
